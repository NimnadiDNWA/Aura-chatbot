# Aura-chatbot

Aura is a beginner-friendly chatbot built using Python and the ChatterBot library.  
It can engage in simple conversations and can be trained with custom responses for topics like IT, history, education, and more.

---

## 💡 Features

- Friendly chatbot powered by ChatterBot
- Basic conversation in English
- Easy to add custom Q&A
- Can be extended with factual responses or logic (e.g., math)
- Simple input/output loop in terminal

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/NimnadiDNWA/aura-chatbot.git
cd aura-chatbot
---


Install Requirements
pip install chatterbot
pip install chatterbot_corpus

🧠 How It Works
The bot is created using ChatBot from chatterbot.

It is trained on the English language corpus and optionally on custom lists.

It uses BestMatch logic to find the closest response.

The user types in the terminal, and the bot replies until the user says "bye".
